# دارایی‌های بصری Alfred-Online

## `bot-avatar.png` — عکس پروفایل ربات

۵۱۲×۵۱۲ · قرمز رسمی برند `#D8132A` · فلش سفید

**نشان بازطراحی نشده.** فایل رسمی `akharinkhabar-arrow-white.png` از کتابخانهٔ
هویت بصری مخزن دانش Alfred (`assets/brand-identity/`) بدون تغییر هندسه ترکیب
شده. راهنمای همان کتابخانه صریح است:

> فلش (`arrow`) لوگوی فشرده/کوچک رسمی است؛ از لوگوتایپ کامل جدا شده تا در
> فضاهای کوچک (هدر، favicon، avatar) جداگانه استفاده شود.

### سه تصمیم پشت این ترکیب

**جای‌گذاری.** مرکز جرم بصری فلش ۱۴ پیکسل بالا-چپِ مرکز کادر است، چون بریدگی
swoosh جرم را از پایین‌راست برمی‌دارد. وسط‌چین کردن روی مرکز جرم، نشان را
پایین-راست می‌انداخت؛ وسط‌چین کادر، کمی بالا-چپ. لنگر نهایی یک‌سوم راه از کادر
به‌سمت جرم است، به‌علاوهٔ ۸ پیکسل پایین.

**اندازه.** نشان ۵۱٪ عرض بوم است و دورترین نقطه‌اش ۱۸۰ پیکسل از مرکز فاصله
دارد — یعنی با فاصلهٔ راحت داخل دایرهٔ محاطی (شعاع ۲۵۶).

**دایره، نه مربع.** تلگرام عکس پروفایل را **دایره‌ای** برش می‌زند. طرح روی
همان قضاوت شد نه روی مربع؛ `bot-avatar-preview.png` همان نمای دایره‌ای در
اندازه‌های ۴۰ تا ۱۲۰ پیکسل است.

### چرا این نشان برای این ربات

فلش برند خودش «فرستادن» را می‌گوید — همان کاری که این ربات انجام می‌دهد. و از
آواتار کانال خبر (صورتک + نوار قرمز با لوگوتایپ) کاملاً قابل تفکیک است.

### ست کردن

Bot API متدی برای تغییر عکس پروفایل خودِ ربات ندارد. از راه @BotFather:
`/setuserpic` → انتخاب ربات → فرستادن `bot-avatar.png`.
